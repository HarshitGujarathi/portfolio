# Harshit Gujarathi — Device Portfolio

A scroll-driven React + Vite portfolio that transitions through desktop, laptop, tablet and phone device scenes.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React
- Vite
- GSAP
- ScrollTrigger
- Responsive CSS

## Main files

- `src/main.jsx` — portfolio content, device scenes and GSAP animation
- `src/styles.css` — responsive design and device styling
- `index.html` — Vite entry document

## Personal content

The portfolio is populated from the supplied Harshit Gujarathi resume, including Ardra, Clinderma, Data Lineage, skills, certifications and contact/project links.
